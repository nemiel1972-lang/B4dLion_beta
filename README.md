B4dLion.v1.3 – Neu

⚠ Alle neuen Funktionen sind im TESTING. Bitte Fehler melden.

Neue Slotverwaltung (Startseite: „Slot management“, Modus „New“) (Testing): Alle freien Slots bilden einen gemeinsamen Pool. Brain und Farm kommen abwechselnd dran, es gibt keine Prioritäten mehr. Der Expeditions-Block bleibt frei. Es gibt feste Reserven für dich („Frei halten“), den Defender (Notfall, plus ein Slot nach einer Spionagesonde), die Hide-Flotte und den Schlaf (ab 2 Stunden vor dem Einschlafen). Discovery, Harvest und Kolonisieren behalten ihre Obergrenze. Startseite und Browser-Kachel zeigen Pool, Reserven und Live-Belegung je Worker. Standard bleibt der alte Modus.
Spywatch (neu, Security) (Testing): überwacht im Schlaf auf Spionagesonden und Angriffe: Alarmton, Telegram, überwachte Himmelskörper und ein Sondenzähler („Spieler X hat N Sonden in T Minuten geschickt“). Angriffs-Checks des Defenders laufen bei Bedarf sofort, auf Wunsch auch bei ausgeschaltetem Defender („Zwangsaktivierung“). Standard aus.
Phalanx (neu, Fleet&Farm) (Testing): scannt ganze Systeme mit der Sensor-Phalanx der Monde, mit Mondliste, Fortschritt, Ergebnissen je System und Reitern „In flight / Gone / History“. Standard aus, 40.000 Deuterium je Scan.
Defender (Testing): „Hide Deathstars“ versteckt Todessterne auf eigenen Monden, „Rohstoffe verstecken“ legt sie kurz vor dem Einschlag in einen abbrechbaren Bau. Ein Journal zeigt, was erkannt und getan wurde.
Tagespausen (Testing): zufällige kurze Pausen des ganzen Kontos über den Tag (Security & Sleep).
AutoFarm: Fastfarm greift Ziele aus dem Galaxie-Cache ohne Spionage an, Zielgedächtnis merkt verteidigte Ziele, „Full rescan“ je Scanbereich. Die Startkachel zeigt die Betriebsart.
Manual spy (neue Funktion) (Testing): arbeitet ähnlich wie die Systemspionage. Hat das Konto keine Klasse oder Allianzklasse mit Systemspionage (z. B. Entdecker, Händler), wird Einzelspionage genommen, das gilt für aktive Spieler. Dazu gibt es eine Zeile „Einzel-Spio“ für eine einzelne Koordinate. Arbeitet im Verbund mit Hunter und Phalanx.
Belohnungen (Testing): Der Schalter auf der Startseite entscheidet, ob der Worker liest. Die Seite zeigt die Schalter immer. „Aufgaben automatisch erledigen“ ist jetzt standardmäßig aus. Flottenaufgaben („Versende eine Flotte“) macht der Bot per Stationierung mit sofortigem Rückruf. Zählt das Spiel das nicht, steht die Aufgabe auf manuell.
Galaxie-Cache gilt über Instanzen hinweg, eine Datei je Universum. Neue Scanrichtung, Hunter-Spionage vom nächsten Himmelskörper.
Oberfläche: globaler Haken „Hide data“ in der Leiste, Haken „Mark new fields“ für die gelbe Markierung neuer Felder, Zeiten in Ortszeit. Die Startseite zeigt neue und entfernte Optionen seit dem letzten Start.
Repatriate: Rückholung per Sprungtor möglich.
AutoTrader (neu) (Testing): verbraucht den Nicht-Metall-Händler mit kleinen Tauschen.
Auktionator eingebaut (Testing): bietet bewusst fair. Automatische Gebote enden 3 Minuten vor dem Ende der Auktion.

B4dLion.v1.3 – What's new

⚠ All new functions are in TESTING. Please report bugs.

New slot management (start page: "Slot management", mode "New") (Testing): all free slots form one shared pool. Brain and Farm take turns, there are no priorities. The expedition block stays free. Fixed reserves for you ("Keep free"), the Defender (emergency, plus one slot after a probe), the Hide fleet and sleep (from 2 hours before going to sleep). Discovery, Harvest and Colonize keep their upper limit. Start page and browser tile show pool, reserves and live use per worker. The old mode stays the default.
Spywatch (new, Security) (Testing): watches for espionage probes and attacks while asleep: alarm sound, Telegram, monitored celestials and a probe counter ("player X sent N probes in T minutes"). Defender attack checks start at once when needed, if wanted also with the Defender off ("forced activation"). Off by default.
Phalanx (new, Fleet&Farm) (Testing): scans whole systems with the Sensor Phalanx of your moons, with moon list, progress, results per system and tabs "In flight / Gone / History". Off by default, 40,000 deuterium per scan.
Defender (Testing): "Hide Deathstars" hides Deathstars on your moons, "Hide resources in a build" puts them into a cancellable build shortly before impact. A journal shows what was detected and done.
Daily breaks (Testing): random short pauses of the whole account during the day (Security & Sleep).
AutoFarm: Fast farm attacks targets from the galaxy cache without spying, target memory remembers defended targets, "Full rescan" per scan range. The start tile shows the mode.
Manual spy (new function) (Testing): works like the system spying. If the account has no class or alliance class with system spying (e.g. Discoverer, Trader), single spying is used, this applies to active players. A "Single spy" row spies one coordinate. Works together with Hunter and Phalanx.
Rewards (Testing): the switch on the start page decides whether the worker reads. The page always shows its switches. "Do tasks automatically" is now off by default. Fleet tasks ("Send a fleet") are done by deploying and recalling at once; if the game does not count it, the task switches to manual.
Galaxy cache is shared across instances, one file per universe. New scan direction, Hunter spying from the nearest celestial.
UI: global "Hide data" checkbox in the bar, "Mark new fields" checkbox for the yellow marks, times in local time. The start page lists new and removed options since the last start.
Repatriate: return flight via jump gate possible.
AutoTrader (new) (Testing): uses up the non-metal merchant with small trades.
Auctioneer built in (Testing): bids deliberately fair. Automatic bids stop 3 minutes before the auction ends.
