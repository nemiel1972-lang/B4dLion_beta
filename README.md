# B4dLion.v1.2 – Neu

- Neue Ordnerstruktur: Jede Instanz hat einen eigenen Ordner `account_<Alias>` mit Config, Zugangsdaten, Daten und Logs. Die Umstellung läuft beim ersten Start automatisch, mit Sicherung und Prüfung.
- Startseite: Kachel „Connection“ mit öffentlicher IP und Proxy-Prüfung, Kachel „Instances“ zum gezielten Stoppen und Starten einzelner Instanzen, Auswahl des Heimatplaneten, die Update-Kachel mit Versionswahl wurde überarbeitet.
- Der Heimatplanet wird bei fremdem Heimatwelt-Eintrag automatisch korrigiert.
- Neue Bestätigungs-Popups im Design der Oberfläche (auch im Classic-Design) statt der Browser-Dialoge.
- Farm: „Hold for Review“ heißt jetzt „Review Farmspys“, „Manual spy“ ist ein eigener Reiter. Manual spy merkt sich die Eingaben, kann die Systeme vorher scannen, zeigt Def-Punkte und Flottenpunkte als sortierbare Spalten und nennt die ignorierte eigene Allianz im Klartext.
- Himmelskörper-Auswahl: bereits gewählte Planeten und Monde fehlen in den anderen Listen, ein neuer Eintrag nimmt zuerst ein noch nicht benutztes System.
- AutoColonize: Beschreibung und Sicherheitsabfrage für „Allow Home Planet“.
- Hinweis: Neue Funktionen sind nicht lange getestet.
- Auktionator wieder entfernt

# B4dLion.v1.2 – What's new

- New folder layout: each instance gets its own folder `account_<alias>` with config, credentials, data and logs. The switch happens automatically at first start, with backup and check.
- Start page: "Connection" tile with public IP and proxy check, "Instances" tile to stop and start single instances, home planet picker, reworked update tile with version choice.
- A foreign home-world entry is corrected to your own home planet automatically.
- New confirmation popups in the look of the UI (also in Classic) instead of browser dialogs.
- Farm: "Hold for Review" is now "Review Farmspys", "Manual spy" is its own tab. Manual spy remembers its inputs, can scan the systems first, shows defence and fleet points as sortable columns and names the ignored own alliance.
- Celestial pickers: already chosen planets and moons are missing from the other lists, a new entry takes an unused system first.
- AutoColonize: description and safety prompt for "Allow Home Planet".
- Note: new functions have not been tested for long.
- remove Auctioneer
